# LocalDesk — دستیار محلی شخصی

یک محیط ساده و فارسی برای چت با مدل محلی، گفتگو با منابع، حافظهٔ تأییدشده و انجام تسک با مجوز ابزارها.

**نسخهٔ 0.1.0-alpha.1 برای کاربران فنی و مشارکت‌کنندگان اولیه است.** فعلاً macOS پشتیبانی می‌شود. کیفیت پاسخ، سرعت و درستی استفاده از ابزار به مدل انتخابی بستگی دارد. این پروژه ممیزی امنیتی مستقل نشده است.

## نصب

Python 3.12 یا جدیدتر و Ollama را از منبع رسمی نصب کن. سورس را دانلود کن و در پوشهٔ پروژه اجرا کن:

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
ollama pull qwen2.5:7b-instruct
.venv/bin/python app/launch_assistant.py --chat
```

Ollama باید در حال اجرا باشد؛ در صورت نیاز آن را جدا با `ollama serve` اجرا کن. مدل‌ها همراه پروژه نیستند و دانلودشان فقط با دستور خودت انجام می‌شود.

برای انجام تسک، OpenCode را جدا از منبع رسمی نصب کن و دستور آخر را بدون `--chat` اجرا کن. مدل پیش‌فرض تسک هم محلی است. برای تصویر باید مدل تصویری تعیین‌شده را جدا دانلود کنی. جزئیات و نسخهٔ سازگار در [راهنمای اصلی](README.md) آمده است.

راه‌انداز صفحهٔ مرورگر را با ورود یک‌بارمصرف باز می‌کند. رمز هر نصب تازه روی دستگاه همان کاربر ساخته می‌شود:

```sh
.venv/bin/python app/launch_assistant.py --show-password
```

برای توقف سرویس‌های خود برنامه:

```sh
.venv/bin/python app/launch_assistant.py --stop
```

## داده و حریم خصوصی

نصب اول خالی است. گفتگو، کلید API، تنظیم ایجنت، فونت تجاری، تصویر شخصی یا دادهٔ توسعه‌دهنده همراه سورس نیست. داده‌های خودت بیرون از پوشهٔ پروژه، در فضای اختصاصی LocalDesk نگهداری می‌شوند. با پاک‌کردن سورس، داده‌ها خودکار پاک نمی‌شوند.

چت محلی برای تولید پاسخ اینترنت لازم ندارد. مدل آنلاین اختیاری است و به کلید شخصی تو نیاز دارد؛ در آن حالت متن لازم به ارائه‌دهنده فرستاده می‌شود. «رایگان» بودن سهمیه، همیشگی یا تضمین‌شده نیست.

ذخیرهٔ حافظه به معنی آموزش وزن مدل نیست. حالت «فقط منابع» متن مرتبط را با استناد نقل می‌کند؛ جست‌وجو فعلاً بر اساس واژه است. تولید عکس، صدا و ویدیو و کنترل عمومی برنامه‌های دیگر متصل نیستند.

## مشارکت و تأیید تغییرات

پروژه را Fork کن، تغییرت را در شاخهٔ جدا بساز و Pull Request بفرست. تست‌ها و بررسی حریم خصوصی باید موفق باشند؛ ورود تغییر به نسخهٔ اصلی با تصمیم نگه‌دارندگان است. تنظیم واقعی حفاظت شاخه در GitHub هم لازم است؛ وجود فایل راهنما به‌تنهایی آن را فعال نمی‌کند.

## بررسی امنیت اسکیل‌ها

اسکیل‌های ایجنت اختیاری‌اند و در پوشهٔ [`skills/`](skills/README.md) قرار می‌گیرند؛ هر اسکیل یک پوشهٔ جدا با `SKILL.md`. LocalDesk خودش آن‌ها را اجرا نمی‌کند. قبل از استفاده از اسکیل شخص ثالث با [SkillSpector](https://github.com/NVIDIA/SkillSpector) بررسی کن:

```sh
sh scripts/scan-skill.sh        # بررسی ایستا؛ محتوای اسکیل به مدل فرستاده نمی‌شود
sh scripts/scan-skill.sh --llm  # انتخاب صریح تحلیل معنایی و ارسال محتوا
```

در هر دو حالت فقط نام و نسخهٔ وابستگی‌ها برای بررسی CVE به OSV.dev می‌رود. با هر تغییر در `skills/` همین بررسی ایستا در CI اجرا می‌شود. اسکنر فایل‌ها را بررسی می‌کند و اسکیل را نصب یا اجرا نمی‌کند؛ نتیجهٔ `SAFE` قطعی نیست، به‌ویژه برای متن فارسی یا محتوای تصویری.

مجوز Apache-2.0 اجازه می‌دهد نسخهٔ خودت را با رعایت شروط مجوز تغییر و منتشر کنی. تأیید ما فقط برای ورود تغییر به مخزن و نسخهٔ رسمی خود پروژه لازم است، نه برای هر استفاده یا Fork مستقل.
